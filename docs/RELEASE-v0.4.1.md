首个中文公开试用版，适用于 Windows x64。

## 下载与运行

下载 `STM32Git-v0.4.1-win32-x64.zip`，完整解压后双击 `STM32Git.exe`。电脑需安装 Git for Windows；Keil 编译功能另需本机 Keil、对应编译器和设备支持包。运行免安装版无需 Node.js。

首次启动自行选择工程。发行包没有预设个人工程，也不含用户数据、STM32 源码或固件。

## 本版能力

- 中文按钮式 Git：保存版本、差异与历史、分支冲突、临时草稿、标签、独立目录、GitHub 基础同步。
- 专家工具：操作预览与备份、reflog、手动二分、诊断与离线历史包。
- Keil 快照编译、日志和固件来源归档、手工上板记录、Markdown 笔记、本地检查点。
- 中文快速入门、使用手册、FAQ、功能范围与开发文档。

这是试用版，未签名，不支持 Git 全部高级流程、自动烧录、在线 AI 或完整 LFS 迁移。编译通过不代表硬件通过。使用前阅读仓库 README 和功能范围。

## 校验与升级

`SHA256SUMS.txt` 提供 ZIP 校验值。解压后请保留全部文件。已有使用记录时，先关闭旧版并备份程序旁的 `data/`，再迁入新目录；不要将自己的 data 目录公开分享。
