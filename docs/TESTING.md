# 测试与验证范围

日期：2026-10-29。公开试用版 v0.4.1。

## 可以复现的检查

- `npm run check`：检查源码和脚本 JavaScript 语法。
- `npm test`：基础、协作、专家、GitHub 连接和工程扩展的后端测试；只操作系统临时目录中的隔离仓库。
- `npm run test:ui`：7 项工程扩展界面流程，包含 Markdown、检查点、构建记录、归档和迁移清单；构建器明确标记为 `test-simulation`。
- `npm run test:startup`：空数据目录启动，检查版本、空工程列表、页面错误与外部请求。
- `npm run check:share`：检查待分享源码文件、文本凭据模式、个人路径和相对文档链接。

本轮实际结果记录在 [VALIDATION.json](VALIDATION.json)。界面测试图片来自临时示例工程，隐藏了本机绝对路径。

## 真实 Keil 的验证来源

公开整理前，D1 v0.4.0 已在 Windows 上用实际工程验证：Keil UV4 5.18、ARMCC V5.06 update 1 (build 61)、STM32F103C8、带空格的 `Target 1`。从最终本地成品按钮完成独立快照编译和 AXF 归档，结果为 0 错误、1 个文件末尾换行警告。核对原目录文件保持，未烧录或执行硬件测试。

v0.4.1 保留该编译实现；公开整理主要改变默认工程发现、打包与文档，不携带当时的工程、私有编译日志或固件。公开版的自动化界面验收使用模拟器，因此不能把这次自动化当作对所有真实 Keil 环境的新证明。
