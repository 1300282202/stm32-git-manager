# 功能范围与后续计划

v0.4.1 是基于本地 A、B、C1、D1 阶段成果整理的公开试用版。下面的阶段名用于说明演进，不表示 Git 的全部功能已经实现。

| 阶段 | 已交付 | 当前边界 |
| --- | --- | --- |
| A：日常管理 | 工程选择/初始化、忽略规则、差异、暂存与提交、历史、单文件恢复与备份、仓库署名 | 普通工作区；拒绝外部内容过滤器和不支持的钩子 |
| B：协作 | 分支、合并、冲突、临时草稿、普通提交移植、标签、独立目录、源码 ZIP、GitHub 登录与基础同步 | 拉取仅快进；不强制推送；不移植合并提交 |
| C1：专家起步 | 重置/清理预览与备份、救援分支、reflog、手动二分、反向普通提交、末次说明、只读诊断、bundle 导出/验证、命令帮助目录 | 不完整重写共享历史；不自动执行任意命令或测试脚本 |
| D1：工程扩展 | Keil 快照编译、固件来源归档、手工验证记录、基础 Markdown、本地检查点、规则草稿、LFS 检测、迁移清单 | 无自动烧录、在线 AI、完整 LFS/迁移包；工程外依赖和自定义构建脚本不适配 |

## 后续候选

- 完整交互式变基、提交拆分、补丁应用和导入。
- 子模块、稀疏/部分检出、签名与验证。
- LFS 读写与历史迁移、其他托管平台适配。
- 更广的 Keil/编译器组合、工程外依赖和构建脚本适配。
- 更完整的 Markdown 与工程迁移包。
- 在线智能辅助或硬件工作流，需另行设计权限和验证范围。

这些是候选范围，未承诺完成日期。Issue 可用于描述具体场景和期望行为。
